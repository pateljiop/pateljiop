## 👋 About Me

I'm Hariom, a college student and web developer focused on building practical digital solutions — from responsive business websites and landing pages to Python utilities, automation workflows and AI-assisted tools.

I care about useful products, clean implementation, responsive design and building things that can solve real problems.

## 🧩 What I Build

- 🌐 **Business Websites** — modern, responsive websites for businesses and service providers
- 🎯 **Landing Pages** — focused pages designed around a clear goal
- 🔄 **Website Redesigns** — cleaner, faster and more credible web experiences
- 🐍 **Python & Automation** — practical scripts, utilities and repetitive-work automation
- 🤖 **AI-Assisted Solutions** — useful AI workflows and lightweight tools
- 🚀 **Deployment & Setup** — hosting, domains, responsive testing and launch support
